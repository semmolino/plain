# sRGB-Farbprofil für PDF/A-3

`sRGB2014.icc` ist das sRGB-v2-Profil des International Color Consortium
(Copyright International Color Consortium, 2015), unverändert bezogen von
https://registry.color.org/rgb-registry/srgbprofiles
(Datei `profiles/sRGB2014.icc`, 3 024 Bytes,
SHA-256 `384b832de3412066743b52a75ee906b6fb9fb8d9e09e936fc2c43223815c6e0a`).

Es steht als OutputIntent im ZUGFeRD-Hybrid-PDF (`services_einvoice_pdf_embed.js`),
damit die Gerätefarben des Chromium-PDFs (DeviceRGB) nach PDF/A-3b zulässig sind.
Die Profile des ICC dürfen frei verwendet, kopiert und weitergegeben werden,
solange sie unverändert bleiben — die Datei hier also nicht bearbeiten.
